# 🧠 AI Cognitive Disruptor Skill

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)]()
[![Prompt as Code](https://img.shields.io/badge/Pattern-Prompt_as_Code-green.svg)]()

本仓库提供了一套工程化的 AI "认知破局引擎"。核心目的是通过算法化、状态机化的 Prompt 结构，强行阻断大模型基于概率预测的“平庸常识”输出，逼迫其输出高维、反常识且具备工程落地价值的架构级解法。

## 🎯 核心机制
1. **Cache Purge**: 强制废弃行业默认解法。
2. **First Principles**: 剥离技术栈，直击物理与逻辑底层。
3. **Cross-domain Mapping**: 跨界映射重构工程问题。
4. **Constraint Mutation**: 施加极端约束，逼出非对称解法。
